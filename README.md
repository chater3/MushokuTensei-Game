# REBORN: SECOND LIFE

3D-игра от первого лица по канону **Mushoku Tensei: Jobless Reincarnation** (история 23+1 тома) на **Unreal Engine 5.7**.

![Unreal Engine 5.7](https://img.shields.io/badge/Unreal%20Engine-5.7-blue)

## О чём игра

Вторая жизнь Рудеуса Грейрата — от рождения в деревне Буэна до похода к Змею и дальше по сюжету романа. История без выдумок: каждая сцена, тренировка и драка следуют канону, исходы каноничные.

- **203 сцены** сюжета, **7 квестов**, **14 локаций**
- **169 озвученных реплик** — разные голоса каждого персонажа, синтез edge-tts в стиле Анилибрии
- **5 музыкальных тем** (тема, грустная, фоновая, бой, финал)
- Модели и текстуры с Sketchfab: Рудеус (все стадии, включая без руки), Сильфиета, Рокси, Эрис, Руйджерд и другие
- Режимы: ГЕРОЙ (статы), МАГИЯ (стихии и заклинания), КАРТА МИРА

## Геймплей

- **Бой в реальном времени от первого лица**: ЛКМ — удар, ПКМ — заклинание
- Тренировки и драки управляемые, но всегда по канону
- При HP = 1 — кровавая надпись **«ВЫ ПРОИГРАЛИ»**, после которой сюжет продолжается (HP не восстанавливается — как в оригинале)
- Реплики идут на фоне локации; во время диалога игрок заморожен

## Управление

| Клавиша | Действие |
|---|---|
| WASD + мышь | движение и обзор от первого лица |
| ЛКМ / ПКМ | удар / заклинание (в бою) |
| Space | прыжок |
| Enter / Space | дальше по сюжету |
| 1–5 | выбор реплики |
| V | голос (вкл/выкл) |
| M | карта мира |
| G | панель героя |
| K | панель магии |

## Структура репозитория

```
RebornSecondLife/
├─ Source/RebornSecondLife/   C++ модуль (GameMode, GameInstance, StoryWidget…)
├─ Content/RS/
│  ├─ Levels/Main.umap        основная карта
│  ├─ Story/scenes.json       203 сцены сюжета
│  ├─ Story/voice_map.json    169 голосов
│  └─ Audio/                  голоса и музыка (.uasset)
├─ Config/                    настройки проекта
└─ RebornSecondLife.uproject
```

Служебные: экспортер сюжета `export_story.py`, генерация озвучки edge-tts, скрипты очистки уровня — в рабочей папке разработки.

## Сборка и запуск

1. Откройте `RebornSecondLife.uproject` в Unreal Engine 5.7 (или соберите модуль: `Build.bat RebornSecondLifeEditor Win64 Development -project=...`)
2. Запуск в окне 1920×1080:
   ```
   UnrealEditor.exe RebornSecondLife.uproject -game -windowed -resx=1920 -resy=1080
   ```
3. Первая игра начнётся с пролога; сохранения — `Saved/SaveGames/SL0.sav`

## Технические детали

- UE 5.7, C++ модуль `RebornSecondLife`, карта `/Game/RS/Levels/Main`
- GameInstance: `RSLGameInstance` (сюжет, прогресс, озвучка, музыка), GameMode: `RSLGameMode` (бой, ввод)
- Стартовые статы: сила 5 / ловкость 6 / интеллект 8 / выносливость 5 / удача 5

## Канон

Сюжет следует оригинальному роману (23+1/24 тома). Все канон-правки внесены в `story_data.py` и экспортированы в `Content/RS/Story/scenes.json`.
